FAQ AI Bot — Strapi Plugin

An AI-powered FAQ chatbot plugin for Strapi. Drop it into any Strapi project and get an intelligent FAQ assistant in your admin panel.

Node.js >= 18 Strapi ^5.0.0 npm: nui-strapi-chatbot-plugin
To test the chatbot API, use the nui-strapi-chatbot-react package as a simple frontend UI.

Installation

npm
yarn
pnpm
npm install nui-strapi-chatbot-plugin@latest
yarn add nui-strapi-chatbot-plugin@latest
pnpm add nui-strapi-chatbot-plugin@latest

Build & start

# build then run dev server npm run build npm run develop

Usage

  1. 1Start your Strapi app.
  2. 2Open the admin panel and navigate to FAQ AI Bot in the sidebar.
  3. 3Enter your OpenAI API key. Ensure gpt-4o-mini and text-embedding-3-small are available on your account.
  4. 4Add your frontend base domain (used to resolve card assets from the public folder).
  5. 5Add a contact link so the AI can surface it when users ask.
  6. 6Save the configuration.
  7. 7Add your FAQ entries in the Chatbot-FAQ collection.
  8. 8Test the chatbot directly from the admin panel.

Updating

npm install nui-strapi-chatbot-plugin@latest # then rebuild npm run build && npm run develop

Security

Admin endpoints/collections, /usage, and /validate-key require Strapi admin auth and are not publicly accessible.
API key storageYour OpenAI key is stored in the Strapi plugin store and is never returned to the browser in plaintext.
Public /ask endpointRequired by the frontend widget. Apply rate limiting at your reverse-proxy or CDN in production to prevent billing abuse.

Troubleshooting

  • Make sure the base domain is set correctly before testing.
  • Only add FAQ entries after providing a valid API key.
  • If you see a version mismatch during install, run: npm install --legacy-peer-deps
